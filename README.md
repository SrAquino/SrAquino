## Projetos em destaque

### [JP Pedras](https://jppedras.vercel.app/)

Aplicação web para apresentação e gerenciamento de um catálogo de pedras, com área administrativa e identificação de vendedores por links personalizados.

**Tecnologias:** Next.js, React e Firebase.

### [BioRecicla](https://biorecicla.vercel.app/)

Aplicação web desenvolvida para o setor de reciclagem, com interface responsiva e foco na apresentação clara dos serviços e informações da empresa.

**Tecnologias:** React, Next.js e JavaScript.

### [Physio Games](https://sol.sbc.org.br/index.php/sbcas/article/view/35547)

Projeto acadêmico voltado ao uso de jogos e tecnologias interativas na área de saúde, com trabalho publicado nos anais da Sociedade Brasileira de Computação.

**Áreas:** desenvolvimento de jogos, interação humano-computador e saúde digital.

### [YouTube Captions](https://github.com/SrAquino/Youtube_Captions)

Pipeline experimental para coleta de vídeos, extração de áudio, transcrição de legendas e processamento de dados, incluindo vetorização e agrupamento de conteúdo.

**Tecnologias:** Python, SQLite, processamento de imagens e aprendizado de máquina.
